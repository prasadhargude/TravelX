# **App Name**: In-Vehicle Social Pulse

## Core Features:

- Local Moment Detection: Detect interesting moments from video/images locally using OpenCV and YOLOv8.
- Local Sentiment Analysis: Analyze sentiment and scene context locally using FER and custom rules.
- AI-Powered Post Generation: Use local GPT-2 to generate captions and Stable Diffusion to create images for social media posts. This tool generates posts based on mood, scene, and metadata.
- Real-Time User Interaction: Provide a Streamlit dashboard for approving, rejecting, or editing AI-generated posts.
- Local Feed Simulation: Simulate a local social media feed displaying approved posts.
- Simulated Vehicle Data Input: Ingest driving video, image and mood data. This data serves as a live input feed.

## Style Guidelines:

- Primary color: Deep teal (#008080) to evoke a sense of journey, safety and calmness.
- Background color: Soft, desaturated light gray (#F0F0F0) to provide a clean and modern backdrop.
- Accent color: Muted gold (#B8860B) to highlight key elements and actions.
- Body and headline font: 'Inter', a grotesque-style sans-serif known for its modern, machined, objective, neutral look.
- Use modern, line-style icons for navigation and actions. Ensure icons are intuitive and easily recognizable.
- Implement a clean, card-based layout for displaying AI-generated posts and user interactions.
- Use subtle transitions and animations to enhance user experience when generating or approving posts.
